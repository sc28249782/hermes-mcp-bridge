## 3. ขอบเขตและข้อจำกัดของหลักฐาน acceptance

- Acceptance เป็น **synthetic-backend evidence เท่านั้น**: fixture รัน production `server()`/`ContextRegistry` จริงบน Dev tunnel จริง แต่ Hermes เป็น mock transport และ Codex เป็น stub — ไม่ใช่ real-backend หรือ native-backend acceptance
- ชั้นหลักฐาน: durable rows/audit ตรวจซ้ำได้; response payload รายละเอียดเป็น parent observation; raw response เต็มไม่ถูก persist ใน fixture จึงไม่มีหลักฐาน raw ครบทุก response
- close-at-bind เป็น test-only hook ไม่ใช่ natural network race; uncertain replay ไม่ได้ถูกพิสูจน์ผ่าน transport
- Restored Dev baseline `1.2.4`/`e7add7e` และ production v1.2.7 ไม่ถูกแตะ; รายละเอียดอยู่ที่ [acceptance record](CONTEXT-LIFECYCLE-DEV-ACCEPTANCE-TH.md)
