## Quiescence, backup และ switch

หยุด production instance แบบ exact (ตรวจ identity ของ process ก่อนเสมอ ไม่ substring match) ก่อนคัดลอก.
คัดลอก config/state แบบ quiescent copy หลังหยุด instance แล้ว; ไม่มี DB merge, replay หรือการยกเลิกงานของผู้อื่น.
เก็บ private backup ของ profile/config ก่อน switch (mode 0600) และคง deployment v1.2.6 เดิมไว้ใช้ rollback ตามหลัก rollback เดิม: ห้ามรวม state ต่างชุดหรือ replay งาน.
สลับ launch เป็น v1.2.7 แล้วรีสตาร์ตผ่าน auth flow เดิม; Dev profile/pin `e7add7e` ไม่ถูกสลับ.

## Decision และงานที่ยังค้าง

Deployment เสร็จสิ้น; production รัน signed v1.2.7.
งานค้างเดิมยังเปิดตาม [release record](V1.2.7-RELEASE-RECORD-TH.md): P2 race design, read-only-mount probe, counters/annotations, Hands v1.3.0 capability gate และ MCP Events BLOCKED.

หากต้อง rollback ให้หยุดรับงานและตรวจ active jobs/process ก่อน.
หยุด instance ใหม่เมื่อปลอดภัย แล้วคืน profile command เป็น v1.2.6 และ restart ผ่าน auth flow เดิม.
ห้ามรวม state ต่างชุดหรือ replay งานที่มีผลข้างเคียงโดยเดา.
หากมีงานใหม่หลัง switch ต้องตรวจ state และผลกระทบก่อนเลือก snapshot สำหรับ rollback.
